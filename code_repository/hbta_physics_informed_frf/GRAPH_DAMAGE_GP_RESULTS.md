# Rank-one graph-GP HBTA prototype: final preliminary assessment

## Hypothesis

A healthy graph Gaussian field plus damage directions generated by exact
rank-one reductions of a graph-Laplacian stiffness surrogate can distinguish
localized damage from recording-domain shift better than unstructured or
healthy-only GP baselines.

The graph model is exact only relative to the surrogate
`L = B.T W B`; it is not an exact stiffness model of the physical bridge.

## Data protocol

- Input features: three complex modal-residue shapes for every 60 s P2-noise
  block, normalized for arbitrary modal phase and scale.
- Healthy reference: all fourteen UDS01 blocks.
- Hyperparameters: selected by twofold healthy-only cross-validation.
- Threshold: fourteen leave-one-block-out UDS01 nonconformity scores, using the
  conservative higher 95th percentile (the maximum score).
- External healthy test: all fourteen UDS02 blocks; never used for fitting.
- Damage test: all fourteen blocks from each DS1--DS8; never used for fitting,
  calibration, or method selection.
- Structural control: 100 sensor-label shuffles within AG/AL families, each
  retuned using healthy data only.

## Methods tested

1. Isotropic GP anomaly likelihood.
2. Healthy graph-GP anomaly likelihood with resolvent covariance.
3. Full damage-conditioned Gaussian likelihood ratio using exact rank-one
   covariance updates.
4. Scale-invariant graph-GP damage alignment. This conditions out total
   residual energy and measures only the whitened angle between a residual and
   the candidate rank-one damage directions.

The fourth statistic was introduced only after the full likelihood revealed
that recording-domain residual amplitude dominated the Bayes factor. Both
results are retained; the failed full likelihood is not discarded.

## Main conformal result

| Method | UDS02 false alarm | External macro AUROC | Macro TPR |
|---|---:|---:|---:|
| Isotropic GP | 1.000 | 0.728 | 1.000 |
| Healthy graph GP | 1.000 | 0.824 | 1.000 |
| Scale-invariant damage alignment | **0.000** | **0.891** | 0.500 |

The full unnormalized damage-conditioned likelihood also failed: in the earlier
locked split it produced 100% external false alarms and macro AUROC 0.452.

For the scale-invariant statistic, external AUROC by state is:

- DS1 0.959;
- DS2 1.000;
- DS3 1.000;
- DS4 0.301;
- DS5 1.000;
- DS6 0.990;
- DS7 0.878;
- DS8 1.000.

The conservative conformal threshold controls UDS02 false alarms but reduces
macro TPR to 0.500. In particular, DS4 is not detected and is ranked below the
external healthy recording.

## Robustness audits

Across fourteen circular temporal splits of UDS01, external macro AUROC has
median 0.900 and range 0.835--0.928. Thus the ranking benefit is reasonably
stable. A threshold based on only three calibration blocks is not stable:
external false alarm ranges from 0 to 1 with median 0.75. This is why the primary
result uses leave-one-out conformal calibration over all fourteen reference
blocks.

The critical topology control does not pass. Across 100 shuffled graphs:

- shuffled median external macro AUROC: 0.720;
- shuffled 5th--95th percentile: 0.280--0.968;
- physical graph percentile: 0.81;
- one-sided empirical permutation p-value: 0.198.

Therefore, the physical graph is better than most shuffles but not significantly
better under the predefined 5% criterion. The improvement over ordinary GP
baselines cannot yet be attributed specifically to structural topology or the
rank-one stiffness model. Scale invariance itself is the more strongly supported
mechanism.

## Localization signal

For DS1, the physical model selects AL14--AL18, the known damaged connection, in
11 of 14 blocks (78.6%). It also assigns lateral-bracing relations to DS5--DS7,
which is qualitatively consistent with those interventions. However, only DS1
has an unambiguous one-to-one mapping to a represented graph edge. This is a
promising localization result, but one uniquely mappable damage case is not
enough for a general localization claim.

## Go/no-go decision

**No-go for a general HBTA detection paper claiming that the physical rank-one
graph kernel caused the performance gain.**

**Conditional go for a localization-focused continuation**, but only with a
benchmark containing several independently known single-edge damage locations.
The clean next question would be:

> Given that an alarm already exists, can a rank-one graph-GP posterior localize
> the damaged structural link without a calibrated finite-element model?

HBTA DS1 can remain an external full-scale demonstration. It cannot be the sole
localization validation case. Further tuning on the same HBTA DS1--DS8 records
would risk adapting the method to the benchmark and is not recommended.

## DS1-only follow-up

The subsequent locked DS1 audit is documented in `DS1_LOCALIZATION_AUDIT.md`.
With 1,000 graph-label permutations, the rank-one model localizes AL14--AL18 at
record-level rank one (`p=0.012`). A direct endpoint-contrast baseline is even
stronger (14/14 block-level rank one, `p=0.010`). Thus DS1 contains genuine
edge-specific information, but the audit does not support incremental value
from the resolvent graph-GP.
